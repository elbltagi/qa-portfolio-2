# qa-portfolio-2

## The Quality Journey — DEPI Graduation Project Website (Version 2)

An interactive, award-winning digital exhibition and presentation website for the **Digital Egypt Pioneers Initiative (DEPI)** Software Testing graduation project.

### Project Context
- **Program**: Digital Egypt Pioneers Initiative (DEPI)
- **Track**: Software Testing
- **Target Application**: [Automation Test Store](https://automationteststore.com/)
- **Duration**: 9 Weeks
- **Stage**: Planning / Proposal Phase

### Features & Architecture
- **Modern Creative Direction**: Inspired by editorial portfolios and Swiss typography (Syne, Plus Jakarta Sans, Space Mono).
- **Interactive Motion**: GSAP 3.15 + ScrollTrigger fluid motion, masked typography, and expanding website preview.
- **Supabase Integration**: Live data connection to the graduation project Supabase database.
- **Eight Comprehensive Sections**:
  1. Vision & Hero Headline (`Quality Starts with Curiosity.`)
  2. Project Overview & Mission
  3. Curators / Verified Trainees Team Gallery
  4. User Stories & Functional Feature Explorer
  5. Testing Types Strategy Matrix
  6. Testing Activities & QA Workflow
  7. Test Levels Architecture
  8. 9-Week Planning Roadmap Timeline
- **Fully Responsive**: Optimized across all viewports from mobile (320px) to ultra-wide desktop.
